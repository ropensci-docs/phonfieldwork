# Praat Pitch tier to dataframe

Convert a Praat Pitch tier to a dataframe.

## Usage

``` r
pitch_to_df(file_name, candidates = "")
```

## Arguments

- file_name:

  string with a filename or path to the Pitch tier

- candidates:

  Praat Pitch tier contains multiple candidates for each time slice, use
  the value `"all"` if you want to get them all

## Value

a dataframe with columns: `time_start`, `time_end`, `frequency` and, if
`candidates` = `"all"`, `candidate_id` and `strength`
